How to create a scoped GitHub token (1 minute)
  1. Open GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Click Generate new token and choose Only select repositories → yyoon62/notes.
  3. Under Repository permissions, set Contents to Read and write.
  4. Generate, copy the token, and paste it above. It is stored only in this browser’s localStorage.
